# User Guide & Walkthrough

This guide provides an overview of the application's features.

## 1. Dashboard / Activity Feed
The main landing page shows your recent activities.

![Activity Feed](images/activities_feed.png)
*Displays a list of recent activities with key metrics like distance, duration, and pace.*

## 2. Activity Detail
Clicking on any activity reveals the full map path, elevation charts, and granular stats.

![Activity Detail](images/activity_detail.png)
*Detailed view with interactive map, pace/elevation graphs, and split times.*

## 3. Sleep Analysis
Deep dive into your sleep patterns, including sleep stages, heart rate variance (HRV), and body battery.

![Sleep Dashboard](images/sleep_dashboard.png)
*Visualizes sleep duration, stages (Deep, Light, REM), and recovery metrics.*

## 4. Steps & Trends
Track your daily movement against your goals over different time ranges (1 week, 4 weeks, 1 year).

![Steps Trends](images/steps_trends.png)
*Shows daily step counts vs. targets. The dotted line indicates your daily goal.*

## 5. AI Insights
Get personalized coaching advice generated by OpenAI based on your recent data.

![AI Insights](images/ai_insights.png)
*Daily recommendations for training, recovery, and nutrition.*

## 6. Deep Analytics (Advanced)
A powerful statistical suite for uncovering hidden patterns in your longitudinal data using R.
Features include PCA, Factor Analysis, Clustering, and Regression Modeling.

👉 **[Read the full Deep Analytics Documentation here](DEEP_ANALYTICS.md)**

### How to update these screenshots
1. Run the app locally or via Docker.
2. Navigate to each page mentioned above.
3. Take a screenshot (Win+Shift+S on Windows).
4. Save the files into the `docs/images/` folder with the filenames specified above (`activities_feed.png`, `activity_detail.png`, `sleep_dashboard.png`, etc.).
